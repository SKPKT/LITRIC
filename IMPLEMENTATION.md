# Pelan pelaksanaan LITRIC

1. Audit sumber sebenar; asingkan sekolah ABA6052 dan kekalkan hash, nombor baris, tahun serta semantik yang belum disahkan.
2. Model D1 berbilang sekolah; identiti melalui ChatGPT dan peranan di pelayan; R2 untuk sumber, bukti dan sandaran.
3. Import CSV/XLSX/ZIP, pratonton, pemetaan, pendua, konflik identiti, pengesahan tempoh dan pembatalan kelompok.
4. Dashboard, profil, pencapaian dan analitik menggunakan satu fungsi agregasi dengan kawalan pertindihan.
5. Sasaran, bacaan berbantu, program, sijil PDF/QR, laporan Excel/PDF, konfigurasi SMARTLIB dan audit.
6. Uji sempadan bintang, import idempoten, snapshot, peranan, skop sekolah dan padanan laporan; semak UI dan terbitkan secara peribadi.

Tiada projek SMARTLIB, logo sekolah, katalog atau kelayakan API dibekalkan. Adapter berasingan tidak mengubah SMARTLIB. Tahun 2025 pada nama set AINS datang daripada arahan pengguna sahaja; fail tidak mengandungi tarikh laporan. Kelas dan tahun CSV tidak direka.
